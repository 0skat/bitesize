# Code of conduct

BiteSIze is a small personal project. Be kind in issues and pull requests.

- No harassment, hate, or personal attacks.
- Do not post secrets, SMTP passwords, or live `data/` dumps.
- Assume people are running this on their own machine, not as a hosted service.

Maintainers may close issues or PRs that ignore this. Report security problems via [SECURITY.md](SECURITY.md), not a public issue.
