# Local session notes (optional)

Copy this file to `MOBILE_HANDOFF.local.md` (gitignored) for personal handoff notes.
Do not commit emails, API keys, worker URLs, or machine-specific paths.

- Cursor worker URL and account (if using mobile agents)
- Local project path and venv activation command
- Current debugging focus and next prompt to paste
- Personal SMTP/Kindle checklist (use placeholders in any shared notes)
